Import & export

Import a CSV (columns: platform, author, rating, date, title, text, url), a JSON backup from this app, or your Google reviews export: the reviews.json file from Google Takeout → Google Business Profile. It brings in every Google review with its rating, date, text and whether you replied. You can pick several files at once. Reviews already in the tracker are skipped.

Automatic sync

Review sites block browsers from reading their pages directly, so automatic pulls use each site's official API from the included Node script. Run it on a schedule, then click “Load data/synced.json” (or just reload — the app picks it up automatically when served over http).

GOOGLE_PLACES_API_KEY=… YELP_API_KEY=… TRIPADVISOR_API_KEY=… \
  node review-tracker/sync/sync.mjs

See review-tracker/README.md for how to get each key.
